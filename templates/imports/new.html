How it works

  1. Map columns to fields. The mapping is saved for the next file from the same source.
  2. Validate. Phones are normalised, GSTIN, email and dates are checked, duplicates flagged within the file and against existing records.
  3. Dry run. See new, updated, skipped and needs-fixing counts, with a downloadable error file.
  4. Commit as one batch. Every row keeps its source, original ID and raw values.
  5. Roll back the whole batch within 14 days if needed.
